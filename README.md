## Introduction

Ugarit Telescope is an elegant debug assistant for the Ugarit framework. Telescope provides insight into the requests coming into your application, exceptions, log entries, database queries, queued jobs, mail, notifications, cache operations, scheduled tasks, variable dumps and more. Telescope makes a wonderful companion to your local Ugarit development environment.
